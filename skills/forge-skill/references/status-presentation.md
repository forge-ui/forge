# 状态表达默认规则

2026-11-02 R2收尾修订：推荐新页面默认使用纯文本状态。此为代理的设计推荐，未记为用户已验收；不以样式选择阻塞规范交付或要求用户先审阅图册。

已有项目有明确约定时先继承，不批量改页面。本仓纯文本约定：危险/禁用使用text-fg-red，失效/中性使用text-fg-grey-500，其余黑字；分类、角色、标签使用纯文本。状态含义必须用文字表达，不能仅依赖颜色。

soft StatusBadge保留为可选方案：确有大量状态扫读需求时，说明收益和视觉密度影响，再在该页面方案中提出。Core存在此API不等于默认采用；不自动使用solid、彩虹枚举或自制状态控件。

检查：新方案是否沿用项目约定或上述默认值；例外是否有业务理由；规范、skill与检查清单是否一致。结构示意不等于真实组件展示，实施和用户验收单独记录。
