## 其他来源差异

- analytics 下部三等分和表格双栏断点由 lg 改为 xl；属于响应式策略调整，不是纯组件替换。
- 商品表单内部 gap 从 8px 改为 16px；辅助栏间距从 12px 改为 16px。
- 商品变体行从三个等宽字段加自动宽按钮，改为 4/3/3/2 跨度，改变了字段和操作区分配。
- 窄屏堆叠属于必要的适配能力，但不意味着宽屏固定栏应一起变成比例栏。

## 建议的修正边界

1. case 按真实模板组织：指标区、仪表盘主辅区、嵌套内容区、固定辅助栏的编辑/详情页；每项标明来源模板和适用角色。
2. Grid 保持通用等分栅格。固定辅助栏继续使用模板原有 CSS Grid/Flex 容器，避免为了统一组件而强制比例化；首轮不必新增复杂公共 API。
3. 商品和卖家模板恢复宽屏固定辅助栏，保留有证据支持的窄屏堆叠及防溢出修复；逐项复核原间距和断点。
4. skill 和布局规范明确顺序：先选模板及页面角色，再继承宽度、主次和密度，最后用 Grid 表达适合的部分。通用组件能力不等于默认页面规范。
5. 修正后再做四档视口和交互回归，再继续版本发布。本轮未重复全量交互测试或包检查，未把源码审查当成浏览器验收。
