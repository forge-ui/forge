## 修复与复测（2026-10-15）

以下为本轮已完成修改，原始 103 项记录保留为修复前证据：

- 181：TaskCard 百分比统一有限值、0–100 范围及整数精度；新增 locale / progressLabel，工作分派传入当前语言。复测首次分派 11%，英文 Progress。

- 004：下载进度、收圆、完成展开、自动复位及点击取消；Chrome 完整流程及取消通过。
- 005：发送飞出、完成、飞机回位；Chrome 验证完成后自动恢复可发送。
- 010：执行中、执行完成状态；更换操作清理旧任务计时器。
- 023：全部关闭错峰执行，操作期间禁用冲突输入，卸载清理计时器；关闭动效时立即切换。
- 062：本地模拟登录的加载、失败、重试成功；Chrome 验证失败→取消模拟失败→重试成功，无网络认证请求。

验证：core 275 项测试、案例 115 项测试通过；TypeScript 与 core 构建通过。006/012/022 补充铃铛、收藏装饰与反应粒子；OtpInput 补错误自动清空（clearOnError=false 可保留），LiquidTabs 补菜单退出过渡及退出期间 inert，AddMember 补成功粒子。仍未做全量逐帧相似度验收，不宣称所有细节与原版完全一致。验证码 Chrome 验证错误后清空并可再次成功验证；通知错峰最终为 0 项开启。

## 实测确认的迁移差异

- 001、004、005、081 操作后使用通用处理面板；005 缺原版纸飞机行内完成反馈，004 缺收圆、完成勾和重新展开的状态链。
- 010 主操作仅更新“已选择”，缺执行中与完成状态。
- 023 全部关闭为同时切换；006、012、022 计数正常，但原版铃铛、丝带、粒子等效果未补齐。
- 062 正确填写仅给出校验说明；演示应支持业务驱动的加载、失败与成功，无需接真实认证服务。
- 四个此前新增组件的主要选择、失败重试和切月流程可用；自动复位、退出动画、庆祝效果的差异仍见[源码审计](component-fusion-parity-audit.md)。

实测可用流程包括：短点不误删、长按删除与撤销、本地测试文件读取与移除、工作区切换、Markdown 编辑预览、版本恢复、多人审批、批量归档、任务完成、筛选恢复、失败重试、停止流式回答后重开。049 支持悬停/焦点展开，点击与悬停重合的现象未判为功能故障。

英文及关闭动效仅作代表性抽查：Motion: off 后示例根节点 data-motion=none，未逐组件测量所有动画。测试页读取的最近 20 条 error 日志为空，不代表整站无错误。原版对比主要基于此前源码审计，本轮对 048 追加同操作比较；不把源码 49 项差异计作 49 个浏览器故障。
